# Week 4 Monday – HTTP Fundamentals & REST Principles

## Objective

Understand HTTP requests and responses by testing three public API requests using Postman.

## API Testing Results

| API         | HTTP Method | Status Code | Response Payload                      |
| ----------- | ----------- | ----------- | ------------------------------------- |
| Get Users   | GET         | 200 OK      | JSON containing user information      |
| Get Posts   | GET         | 200 OK      | JSON containing post information      |
| Create Post | POST        | 201 Created | JSON containing the created post data |

## API Endpoints

**1. Get Users**

- URL: https://jsonplaceholder.typicode.com/users
- Method: GET
- Status: 200 OK
- Response file: `get-users-response.json`

**2. Get Posts**

- URL: https://jsonplaceholder.typicode.com/posts
- Method: GET
- Status: 200 OK
- Response file: `get-posts-response.json`

**3. Create Post**

- URL: https://jsonplaceholder.typicode.com/posts
- Method: POST
- Status: 201 Created
- Response file: `create-post-response.json`

## What I Learned

I learned how HTTP requests and responses work, how to use GET and POST methods, and how to identify status codes and JSON response payloads using Postman.
